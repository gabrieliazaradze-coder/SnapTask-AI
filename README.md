# SnapTask AI

A responsive productivity app prototype that turns ideas into editable action plans.

## Current features
- Responsive layout for desktop and mobile browsers
- Example prompts
- Local demo checklist generation (not connected to an AI model)
- Editable task names and completion tracking
- Progress indicator, copy, and reset actions
- No build step required; open `index.html`

## Deploy
This is a static website. It can be hosted on GitHub Pages or Netlify.

## Before a production launch
This is a prototype, not a production AI service. Plans are generated using simple local rules. Add a secure server-side AI endpoint, rate limiting, privacy policy, terms, error handling, and testing before advertising it as AI-powered. Never put secret API keys in browser code. Payment setup must use a provider that supports the seller's country and age/account requirements.
