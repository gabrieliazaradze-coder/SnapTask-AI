# SnapTask AI

A mobile-friendly task-planning prototype hosted on GitHub Pages.

## Installable web app

The site includes a web app manifest and service worker so supported browsers can offer an install option. On Android, open the live HTTPS site in Chrome and use **Install app** / **Add to Home screen** when available.

## Current limitations

- Plan generation uses local demo templates, not a live AI model.
- Plans are saved only in the current browser's local storage.
- No accounts, cloud sync, or payments are connected.
- The manifest uses an SVG icon. Before packaging for Google Play, use a packaging tool such as PWABuilder and complete Android asset, signing, and policy checks.
